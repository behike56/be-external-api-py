# 22_開発用DBの操作

## テーブルの作成

```bash
poetry run python -m src.api.migrate_db
```

## テーブルの削除 (未実装)

```bash
poetry run python -m src.api.migrate_db --delete
```

## テーブルの更新 (未実装)

```bash
poetry run python -m src.api.migrate_db
```

## DBコンテナ内での操作

### コンテナに入る

```bash
docker exec -it fastapi-db-container bash
```

または、Docker Desktopのコンテナタブからコンテナに入る

``` bash
コンテナ名
be-external-api-py_devcontainer-db-1

execタブからコンテナに入る。
```

### テーブルの確認

```bash
psql -U postgres -d fastapi_db
```

## psqlコマンドリスト

```bash
# データベース一覧
\l
# データベースに接続
\c fastapi_db
# テーブル一覧
\dt
# テーブルの詳細
\d
# テーブルの詳細(詳細)
\d+
# 終了
\q
```
